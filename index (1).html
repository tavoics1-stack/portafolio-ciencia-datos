Machine Learning vs. Deep Learning

Machine Learning

Modelos para datos tabulares

En Machine Learning podemos entrenar modelos para encontrar relaciones entre variables y realizar predicciones. En la práctica de mantenimiento utilizamos regresión logística, árbol de decisión, Random Forest, XGBoost, SVM y KNN.

Por ejemplo, a partir de la vibración, temperatura y horas de operación de un equipo, un modelo puede estimar si pertenece a la clase «falla».

Video educativo externo utilizado como material de apoyo.

Deep Learning

Redes neuronales de varias capas

Deep Learning utiliza redes neuronales con distintas capas para aprender relaciones complejas. Algunas arquitecturas, como las CNN, se utilizan con imágenes; otras, como las recurrentes, pueden aplicarse a secuencias temporales.

Una red más compleja no garantiza mejores predicciones. Por eso también conviene compararla con modelos más sencillos y revisar su rendimiento con datos de prueba.

Aplicación de modelos al mantenimiento industrial

¿Qué podemos aprender del ejercicio?

Comparar modelos

Se utilizaron 800 registros simulados para entrenamiento y 200 para prueba. Esta separación permite revisar el comportamiento de los modelos en un conjunto distinto del utilizado para ajustarlos.

Entender los errores

No basta con mirar la exactitud. También interesa saber cuántas fallas quedan sin detectar y cuántos equipos normales se clasifican incorrectamente como posibles fallas.

Estos resultados son de una práctica con datos simulados. No equivalen a una validación en una empresa real.
